# Inventory-Client-Registry-Manual-Testing

Project Overview
This project demonstrates manual testing performed on an Inventory & Client Registry System. The testing focused on validating customer management workflows and ensuring the system functions correctly and reliably.

As a fresher QA tester, this project helped me gain hands-on experience in:
- Functional Testing
- Black Box Testing
- Regression Testing
- Defect Tracking
- Test Case Design
- Data Validation
- Usability Testing

Tech Stack
- Manual Testing
- Microsoft Excel
- Defect Tracking
- 
Testing Scope
The following modules and functionalities were tested:
- Add Customer
- Update Customer Details
- Delete Customer Records
- View Customer Information
- Inventory Management Workflows
- Input Field Validation
- Navigation & Usability Checks

Testing Types Performed
Functional Testing
Verified that all system functionalities worked according to the requirements.

Black Box Testing
Tested the application from the user perspective without accessing the internal code.

Regression Testing
Retested existing functionalities after updates or changes to ensure no new issues were introduced.

Usability Testing
Checked the application for user-friendliness and smooth workflow experience.
